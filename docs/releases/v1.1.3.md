# Progress Bar Reforged v1.1.3

Released September 4, 2026.

This update improves progress calculations, finish estimates, and everyday controls while preserving saved preferences. New installations still use Advanced mode during reviews only.

- Improved progress weighting for New, Learning/Relearning, and Review cards, based on recent Again rates without assuming future learning repetitions. The tooltip explains why the fill can differ from the count-based percentage.
- More precise recorded review time, consistent study-day boundaries, and correct finish times across midnight and daylight-saving changes.
- Deck Breakdown keeps the current finish estimate when opened or reopened, including its copied summary. Decks with buried cards remain visible when Hide empty is enabled.
- Advanced details return when the window is widened. Home and overview counts refresh after collection edits and a new study day.
- More consistent counts in filtered decks and in newly created profiles.
- Improved Enter/Space access to Deck Breakdown, shortcut recording, theme updates in open Settings windows, and visible checkbox checkmarks.

Install or update through [AnkiWeb](https://ankiweb.net/shared/info/1511983907), code **1511983907**, then restart Anki. Alternatively, install the attached `progress_bar_time_left.ankiaddon` through **Tools → Add-ons → Install from file**.
