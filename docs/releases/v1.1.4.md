# Progress Bar Reforged v1.1.4

Released September 8, 2026.

The top/bottom progress bar now sits directly in Anki's layout, removing the empty strip that looked like a resize handle. This update also keeps deck totals current when the bar is hidden and re-enabled, preserves the current screen at study-day rollover, avoids changing Anki's theme, and safely handles malformed numeric settings.

Saved preferences, progress weighting, and the displayed completion percentage retain their existing behavior.

Install the update through [AnkiWeb](https://ankiweb.net/shared/info/1511983907), code **1511983907**, then restart Anki.
